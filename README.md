# 🌌 DHARSHINI T — Cinematic 3D Solar System Portfolio

> An interactive, photorealistic 3D Solar System personal portfolio website for **Dharshini T** — MERN Stack Developer & MCA Graduate.

---

## 🚀 Overview

This portfolio takes visitors on an exploratory journey through an interactive 3D Solar System. Visitors can travel from the **Sun (Solar Core)** out to **Neptune**, exploring professional projects, technical skills, academic credentials, research presentations, and contact channels.

### ✨ Key Features
- **Photorealistic NASA-Inspired 3D Solar System**: Built with Three.js, React Three Fiber, and Drei.
- **Dual Synchronized Navigation**:
  1. *Scroll-based cinematic camera traversal* powered by GSAP ScrollTrigger.
  2. *Interactive 3D planet click navigation* with smooth camera orbit transitions.
- **NASA James Webb / Hubble Inspired Deep Space Environment**:
  - Millions of smooth anti-aliased circular stars with 4-point diffraction flares.
  - Deep-space open star clusters (The Pleiades, Hyades, and Omega Centauri).
  - Multi-layer seamless volumetric nebula sky domes with dark absorption dust rifts.
  - 9 Photorealistic 3D Moons (Luna, Europa, Ganymede, Titan, Callisto, Io, Enceladus, Triton, and Selene-IX).
- **Featured Projects**:
  - **Car Service and Mechanic Hub**: Full-stack MERN platform connecting vehicle owners with service centers and mechanics, featuring 3-tier role-based access control (RBAC), JWT authentication, and MongoDB Atlas.
  - **Parkinson Disease Detection Using Severity Analysis**: Predictive healthcare intelligence model combining CNNs, Random Forests, and Streamlit diagnostic analytics.
- **Responsive Glassmorphism UI**: Minimal futuristic HUD panels built with Tailwind CSS and Framer Motion.

---

## 🛠️ Technology Stack

- **Frontend Core**: React 19, Vite, Tailwind CSS
- **3D Graphics & Physics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation & Transitions**: GSAP, GSAP ScrollTrigger, Framer Motion
- **Icons**: Lucide React
- **Audio & Soundscape**: Web Audio API Procedural Synthesizer

## 📦 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/dharshini201/dharshini_portfolio.git

# Navigate to project directory
cd dharshini_portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Compile and bundle for production
npm run build

# Preview production build locally
npm run preview
```
